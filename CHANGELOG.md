# Changelog

## 2.0.0

- The successor of the Arch OS Manager, in Rust; its first start takes over the old settings and removes what the old manager left
- One binary: terminal or window, English or German
- Update, news, packages, services, system log, clean-up, configuration updates, mirrors, firmware, repair
- Optional packages installed and removed in place
- Next steps after every run
- App menu entry and update notification, also for an installer through `system-manager init`
- Icons in the window and in a terminal with a Nerd Font
- Themes as YAML, Nord built in
- Arch Update GNOME extension set up as an optional package
- Desktop packages offered only where a desktop is installed
- About page with the system, the project and the command line
- AUR package `arch-os-manager`, built from source
