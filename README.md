## Features

- Updates of the repositories, the AUR and Flatpak in one run
- Arch Linux news, read in place
- Package search over what is installed, the repositories and the AUR
- Older versions from the cache or the Arch Linux Archive
- Services of the system and of the user
- Errors of this boot, the harmless ones hidden
- Clean-up that keeps what a recovery needs
- `.pacnew` files merged, compared or taken over
- Mirrors ranked, firmware updated, a broken keyring repaired
- Restart hint after a kernel update
- Next steps after every run
- Notification of new updates, or their count in the GNOME top bar
- Terminal or a window of its own
- English and German
- Themes such as Nord, Catppuccin, Tokyo Night and Gruvbox, or your own

Optional packages add features; **Settings › Optional packages** installs and removes them.

## Installation

From the AUR, where it replaces the Arch OS Manager with an update:

```sh
paru -S arch-os-manager
system-manager
```

The first start adds it to the app menu, where it opens in a window.
